feat(release): v1.2.4 — folder upload & higher file limit

feat: upload a folder directly — pick or drop a folder and the browser
packs it into a zip on the spot (js/zipstore.js, uncompressed zip with
CRC-32), reusing the existing zip upload path so no hand-built zip is
needed. Skips .git, node_modules, .DS_Store and __MACOSX. One-off file
selection and manual zip uploads are unchanged; folder picking/dropping
targets desktop browsers (noted in the UI). Raises the server-side zip
file-count limit from 200 to 5000 for file-heavy zips (e.g. e-books),
keeping the zip bomb size limits.

v1.2.3 is already tagged for the zip upload feature, so the version-bump
guard blocks reusing it; ship these improvements as 1.2.4.
